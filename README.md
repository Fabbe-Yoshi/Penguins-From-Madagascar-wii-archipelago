# Penguins-From-Madagascar-wii-archipelago
This is my first ever project for a game I loved when I was younger. The AP-world is simply installed by either doubble clicking on the file in your file explorer or draging the folder into your Archipelago/custom_worlds. Then create a Yaml by using the Options Creator inside the Archipelago launcher. That's it! Have fun!!!

An unofficial, community-made custom world (`.apworld`) for the **Archipelago Multiworld Randomizer** system. This mod adds randomizer support to *Penguins of Madagascar* on the Nintendo Wii.

## Features
- **Location Mapping:** Fully integrated game progression locations hooked into the Archipelago network.
- **Item Randomization:** Different stages and collectables are mixed into the multiworld pool.
- **Pure Logic Setup:** Built from scratch using native Archipelago APIs with no external file dependencies.

## Installation

## 1. Install the `.apworld` File
1. Download the latest `penguins_madagascar.apworld` from the **Releases** page (or zip the world folder and rename the extension to `.apworld`).
2. Copy the `.apworld` file into your Archipelago custom worlds directory:
   - **Windows:** `%LocalAppData%\Archipelago\Cache\worlds\` (or the `custom_worlds` folder inside your main Archipelago installation directory).

## 2. Emulator / Hardware Setup
Because this game runs on the Nintendo Wii framework, you will need:
- An emulator (such as **Dolphin**) or a homebrew-enabled Wii console.
- A legally sourced ROM/ISO of *Penguins of Madagascar* (Wii).
- *(Optional)* A memory-watching client script or connector to bridge the game state to the Archipelago server.

## Webhost Compatibility
Since this code contains no copyrighted assets or game files, you can generate your game seeds locally using the Archipelago client toolset, and then safely upload the resulting `.zip` player files directly to [archipelago.gg](https://archipelago.gg) to host your multiplayer server lobbies.
